## P3（不阻塞）

### P3-1 `createRoomState`/`relayRoute` 仍允许空 hostToken

- `src/protocol.ts:151-156` 不校验 `roomId`/`hostToken` 非空；`:231-236` host 分支
  只检查 `token !== room.hostToken`，不检查二者非空。
- 实测：
  `createRoomState('R','')` 成功；随后 `addInvite`/`consumeInvite` 正常，
  `relayRoute(room, 'host', '', 'b')` 返回 `{ from:'host', to:'b' }`。
  即空串可作为 host 凭据；而 `isHostToken('')` 因 `nonEmpty` 返回 false，两处不一致。
- 影响：服务器若误传空 hostToken，空 token 就能走 host relay；正常生成器不会，
  但协议层应拒绝。建议 `createRoomState` 拒绝空 `roomId`/`hostToken`，
  `relayRoute` host 分支要求 `nonEmpty(room.hostToken)`/`nonEmpty(token)`。
- 是否阻塞：不阻塞。

### P3-2 握手 payload 类型表仍缺 `room.invite`/`room.closed`，error guard 不严

  interface/guard；`isErrorPayload` 不检查 `message` 类型。
