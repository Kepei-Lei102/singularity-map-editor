## P2

### P2-1 “有通行小格”用 `!blocksMove` 判，窗/洞被排除；base wall 全窗/洞时回退成 99

- 位置：`src/scene/sight.ts:63-83`，尤其 `:73-80`。
- 代码：
  - `terrainById` 只用来判断 `t && !t.blocksMove` 才计入 `passable`；
  - `window` 是 `blocksMove: true, visionCoef: 0.5`（玻璃透视但挡路）；
  - `hole` 是 `blocksMove: true, visionCoef: 0.1`（能看穿，但脚下不能站）；
  - 两者都不算“通行”，因此不参与最小值；若 9 个小格全是窗/洞，
    `passable === Infinity`，`c` 退回 base 系数。base 是墙时就是 99。
- 实测（`/tmp/probe57.mjs`，20×3 全 floor，眼睛 (1,1)，目标 (7.5,1.5)，改动格 (4,1)）：

  | 大格 (4,1) | `cellSightCost` | `visiblePoint` | 应有 |
  |---|---|---|---|
  | base wall + 9 window | **99** | **false** | 窗 0.5，应可见 |
  | base wall + 9 hole | **99** | **false** | 洞 0.1，应可见 |
  | base floor + 9 window | **0.1** | true | 窗 0.5 |
  | base floor + 8 window + 1 grass | **2** | **false** | 窗多数派，约 0.5 |
  | base wall + 8 window + 1 grass | **2** | **false** | 窗多数派，约 0.5 |
  | base wall + 9 wall（对照） | 99 | false | 99，正确 |
  | base wall + 9 floor（56 修复目标） | 0.1 | true | 0.1，正确 |

- 56 的多数派实现在这些格子上分别会给 0.5 / 0.1 / 0.5（按 56 的
  `dominantId` 代码推断）；57 在窗/洞上出现回退，属于“修 56 时新引入”的过挡。
- 根因：`blocksMove` 是**移动**属性，不是**视线**属性。窗和洞都挡路但透光/透视线，
  不该被当作“不可通行”排除。
- 建议：衰减的小格集合应按**视线**属性选取（例如 `visionCoef < FULL_BLOCK` 的
  所有已登记地形，含窗/洞），而不是 `!blocksMove`；全挡死的小格继续交给
  `sightSubcellBlockers`。补 base wall + 9 window、base floor + 9 window、
  window 多数派混合三条回归。

### P2-2 “取最小”让一个 floor 小格压掉整格草地/窗的衰减，过松

- 位置：`src/scene/sight.ts:73-80` 的 `Math.min`。
- 只要 9 格里有一个 floor/rug（0.1），整格系数就变成 0.1；射线即便实际穿过
  8 个 grass 小格，也只按 0.1 累加，`sightSubcellBlockers` 又只处理
  `visionCoef ≥ 99` 的完全挡死块，草地/窗的衰减无处体现。
- 实测：
  - base grass 大格，9 个小格 8 grass + 1 floor：
    `cellSightCost === 0.1`，`visiblePoint(eye→(7.5,1.5)) === true`；
  - 同格 9 个全 grass（无 floor）：`cost === 2`，同一目标 `visible === false`；
  - 55c 的 base-only 实现会给 base grass 的 2，56 的多数派也会给 2；
    57 的 0.1 是新的过松。
- 同样的问题也出现在 `base floor + 8 grass + 1 window`（2，窗的 0.5 被忽略）
  与 `base window + 8 grass + 1 floor`（0.1）等混合格里。
- 建议：整格衰减不要取“最佳通道”的最小值；至少应对**非完全挡死**的小格取
  多数派/规则书主格系数，并补“8 grass + 1 floor 不能降到 0.1”的回归。
  如果以后要做逐射线小格衰减，再单独开版；当前只有整格一个数，取最小会系统性偏松。
