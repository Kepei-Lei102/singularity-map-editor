## 焦点 1：ghostObjectIds 与 objects.ghost

两边都是 host 的同一公式：

- `ghostObjectIds`：`visibleObjects.filter(o => !!o.blocksWhen && !o.blocksWhen.includes(o.state))`（`sync.ts:308`）。
- `objects.ghost`：`!!o.blocksWhen && !o.blocksWhen.includes(o.state)`（`sync.ts:367`）。
- 都不看 host 持久化的 `o.ghost`。

探针确认：

- 可见的 ghost 物件：`objects.ghost=true`、`groups` 里没有该 `objectId` 组、`media` 没有 texA，`checkWorld(pw)` 过；渲染只画虚线，`drawImage=0`。
- 同一物件开态：`groups` 和 texA 都回来，`drawImage` 一张。
- 物件无贴图时 ghost：`groups` 无，`textured` 不出现，标签回图标；没有“组去掉但 realtime 仍画图/媒体仍被引用”的漏。
- 把 `ghostObjectIds` 改成信 `o.ghost` 或删掉组排除，新 ghost 用例都会红。

## 焦点 2：textured 字段

- 只在 `texturedObjectIds` 命中时发：`(m.groups ?? []).filter(g => g.objectId && g.texture && visibleObjectIds.has(g.objectId))`（`sync.ts:309`），然后 `...(texturedObjectIds.has(o.id) ? { textured: true } : {})`（`:367`）。
- 普通可见有图物件：`textured:true`，组和媒体都在。
- 普通可见无图物件：没有 `textured` 字段，标签仍显示图标。
- ghost 有图：`textured:true`，组/媒体都不发。
- ghost 无图：没有 `textured`，标签显示图标。
- host 的 `drawObject` 里 `textured = !!texture || (player && !!o.textured)`（`render.ts:233`），host 分支不读 `o.textured`；探针里给 host 物件塞 `textured:true` 且无贴图，host 仍画彩色方块和图标。
- 仓库内只有 render 的玩家分支和 sync 派生读 `textured`；host 别处没有信任。host 的 `MapObject.textured` 若被导入/持久化，schema 不校验，渲染也不看，是 P3 残留。
