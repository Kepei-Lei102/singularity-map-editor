## P2

### P2-1 确认后“只开判定、没有位移”的成功动作被当成 failed

wrapper 只看 token 的 `facing/x/y/subcell` 和 `pendingGap`，没有看“有没有新开判定”：[trial.ts:394-410](../src/runtime/trial.ts#L394)。

```
确认起跳/攀爬/跳下
→ pendingGap 被清掉
→ 开了 pendingJudgment
→ token 没有位移、朝向没变
→ wrapper 落到最后的 return 'failed'（[trial.ts:409](../src/runtime/trial.ts#L409)）
```

实测（Node 假窗口，真实模块；PC 六维填好，有玩家窗口）：

| 场景 | 玩家窗口收到 |
|---|---|
| 宽 2 格的坑，第三下确认 | `{"ok":false,"kind":"failed","msg":"跳跃判定已开出。他掷完你点「按结果执行」"}`，`pendingJudgment=true`，位置仍 (5,5) |
| 下 2 格，第三下确认 | `{"ok":false,"kind":"failed","msg":"往下跳的判定已开出……"}`，位置仍 (5,5) |
| 上 2 格，第三下确认 | `{"ok":false,"kind":"failed","msg":"往上攀的判定已开出……"}`，位置仍 (5,5) |

代码位置：`beginGapJump` 的判定分支 [trial.ts:502-536](../src/runtime/trial.ts#L502)（判定开出后只 `setTr`，没有向 wrapper 回传成功）；`beginUpClimb` [trial.ts:423-456](../src/runtime/trial.ts#L423)；`beginDownJump` [trial.ts:460-491](../src/runtime/trial.ts#L460)；`beginFall` 的有窗口分支 [trial.ts:600](../src/runtime/trial.ts#L600) 也是“只开摔伤骰、没有位移”。

玩家看到的不是“判定开好了”，而是红条“跳跃判定已开出”。这和第 27 步的 P2 是同一类：**合法成功但带提示**，状态差没有捕获“开判定”这个状态变化。

建议：wrapper 在调用 `trialMoveStep` 前后快照 `pendingJudgment?.id`；如果新增了判定、且没有 turn/move/prompt，就返回 `'prompt'`（或新增 `'judgment'`），让 `onMove` 回 `ok:true`，玩家端显示中性提示。补一条“宽 2 的坑，确认后 `ok:true`、kind 非 failed”的测试；攀/跳下同理。

实测（Node）；UI 红条样式按源码 `PlayerView.tsx:93/157` 推断。

## P3

### P3-1 wrapper 的 `gapBefore` 没绑 token/方向，换人后的有效确认会误判 failed

[trial.ts:398](../src/runtime/trial.ts#L398) 的 `gapBefore = !!getUI().pendingGap` 只看“全局有没有蓄着的确认”。`switchTrialPlayer` 不清 `pendingGap`：[trial.ts:179-186](../src/runtime/trial.ts#L179)。于是上一个角色蓄的坑前确认还在时，切到另一个角色，新角色按下同方向：

- `trialMoveStep` 发现 `armed.tokenId` 不是自己，重新 `setUI({pendingGap: 新角色})`：[trial.ts:302-305](../src/runtime/trial.ts#L302)。
- 新角色没有位移、没有转向、`pendingGap` 本来就有、之后还有；wrapper 落到 `failed`。

实测：A 在坑前拿到 `pendingGap`（ok:true/prompt），切到 B，B 在另一个坑前按下，B 收到 `{"ok":false,"kind":"failed","msg":"前面是坑……再按一次同方向才起跳"}`，但 `pendingGap` 已改成 B。这是有效的“坑前确认”，不是失败。

建议：`gapBefore` 只认 `pendingGap.tokenId === tok0.id && dx/dy` 匹配；或 `switchTrialPlayer` 清掉旧确认。补一条换人后的确认测试。

实测（Node，两个玩家窗口）。
