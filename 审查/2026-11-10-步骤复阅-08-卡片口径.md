## 1) damageLanded 判定矩阵 — 全对

实测（真攻击拿 `trial.event`）：

| 场景 | damage | hpBefore→hpAfter | `damageLanded` |
|---|---|---|---|
| 正常命中（hp6） | 3 | 6 → 3 | **true** |
| 落空（D100=3） | 0 | 6 → 6（miss 也填了数字） | **false**（靠 `damage > 0` 拦） |
| 打已昏厥 hp0（down=true） | 3 | 0 → 0 | **false**，note「这一下数值没有变化（目标已经在倒地状态，或没有可扣的血量）」 |
| 打没血条的 NPC | 3 | null → null | **false**，note「乙 没有血条（角色卡和棋子都没填 HP）；伤害没落地」 |
| 命中把 hp 2→0 | 3 | 2 → 0 | **true** |
| 大成功（D100=99，2 颗） | 6 | 20 → 14 | **true** |
| 特大成功（D100=00，4 颗） | 12 | 20 → 8 | **true** |

`damage > 0 && hpBefore !== null && hpAfter !== null && hpAfter !== hpBefore` 这条口径和账本一致：`settleAttack` 只有 `next !== pool.hp` 才 push hp delta（`trial.ts:811`），没变化就不记。

## 3) PlayerView — 对（按代码路径核对；组件依赖监听推送的 state，没做服务端渲染）

- 落空：`没打中`（未改）。
- 落地：`命中，掉了 N 点血 → x / max`（未改）。
- 不落地：`命中，但数值没有变化（x / max）`——不再写「掉了 N 点血」；`hpAfter === null`（无血条 NPC）时没有括号。
- **tag 在伤害块外**：`{notice.downed === 'dying' && <span className="tag">濒死</span>}`（`PlayerView.tsx:147-148`）不随 landed 消失 → 边界场景玩家窗口仍能看到濒死/昏厥。
- 缺点：`notice.note` 有带过去（`sync.ts:83`，`combatNoticeFor` 里 `note: ev.note`），但 PlayerView 不渲染 → 无血条 NPC 只显示「命中，但数值没有变化」，真实原因（没有血条）被吞掉。建议不落地时优先显示 `notice.note`，没有再用通用句。

## 4) 边界：hp 没变但状态变了 — **确实漏，且比任务里说的更漏**

任务假设「卡片不显示伤害但有 downed tag」——**实际 tag 也在伤害块里面**（`TrialEventCard.tsx:46-47` 位于 `landed ? ... : null` 内），所以不落地时**整个块（含 tag）都不渲染**。

构造（作者描述的那条）：乙 hp0/hpMax6、token 带 `status:{label:'晕厥'}`、**没有 down**；甲攻击命中：

| 武器 | 事件 | 卡片渲染文本 | 底部日志 |
|---|---|---|---|
| 钝器 | hp 0→0，`downed:'down'`，`note:''`（状态 delta 非空所以不生成 note） | `甲 → 乙 D100 = 50 命中，但数值没有变化`（**无昏厥 tag**） | `…命中：乙 的状态从 晕厥 改为 昏厥` |
| 锐器 | hp 0→0，`downed:'dying'`，`note:''` | `甲 → 乙 D100 = 50 命中，但数值没有变化`（**无濒死 tag**） | `…命中：乙 的状态从 晕厥 改为 濒死` |

- **判定：不可接受**。卡片是视觉焦点，这一击最重要的结果（打成濒死/昏厥）在卡片上完全看不到，只剩底部那排小字；锐器把人打成濒死尤其不该靠小字发现。
- 同类还有：hp0 + 已 down + 挂着「中毒」状态被命中 → 状态被清掉，卡片也只说「数值没有变化」（日志才写「状态从 中毒 改为 无」）。
- **建议（一行移动）**：把 `{ev.downed === 'dying' && …濒死…}` / `{ev.downed === 'down' && …昏厥…}` 移到 `landed` 块外，条件改成 `isHit && ev.downed`；同时把兜底句改成能带状态的说法，例如「命中，但 HP 没变（状态改为濒死）」——或让 `settleAttack` 在「hp 没变但状态变了」时也生成 note（现在 `if (r.hit && !deltas.length)` 才写 note，`trial.ts:830`）。
