## P2-1 · 已机器人再高摔会静默重置 `endsAt`，但账本无 delta

**文件:行**

- `src/runtime/trial.ts:701`：`if (oldLabel !== DYING_LABEL) dt.status = t.combat ? {...濒死...} : robotIncoming();`
  - `oldLabel` 是「急救机器人正在赶来」时，也不等于 `DYING_LABEL`，所以这里仍然执行 `robotIncoming()`，生成新的 `{label:ROBOT_LABEL, endsAt: now+3min}`。
- `src/runtime/trial.ts:708-710`：`actualLabel` 取新 status 的 label，仍是「急救机器人正在赶来」，和旧 label 相同，因此**不推 status delta**。
- `src/runtime/trial.ts:738`：note 走 `状态已经是「${oldLabel}」，这次没有变`。

**复现（实际探针）**

```js
setup({ hp: 0, hpMax: 6, combat: false });
update(d => {
  const t = d.maps[0].tokens[0];
  t.status = { label: '急救机器人正在赶来', endsAt: Date.now() + 60000 };
});
settleJump(jumpDown({ injury: 'heavy' }), [], { injuryRoll: 12, injuryBy: 'player' });
```

实测：

- 旧 `endsAt` → 新 `endsAt`：约 **+120030 ms**（原本只剩约 60 s，重置成约 3 分钟）；
- `tok.status.label` 仍是「急救机器人正在赶来」；
- `ev.deltas` 中 **没有 status delta**；
- note：`…；状态已经是「急救机器人正在赶来」，这次没有变`。

**影响**：`robotArrived` / `statusLeft` 看 `status.endsAt`（`trial.ts:1593`、`:1394`），所以急救机器人到场计时被实际延长，但账本没有任何记录，note 还宣称“没有变”。新测试 `非战斗高摔：账本挂急救机器人，不写假的“→濒死”` 只断言 `status.label` 和无 status delta，没有断言 `endsAt`，因此没有抓住。

**建议**：`oldLabel === ROBOT_LABEL` 时保留旧 status，不要重新 `robotIncoming()`；或至少把 `endsAt` 变化写进可见记录/note。补 `endsAt` 断言（或改成“已机器人再摔不重置 ETA”测试）。

### 2）P2-2 非战斗机器人状态

**源码**

- `src/runtime/trial.ts:708-710`：status delta 的 `to` 改为 `dt.status?.label ?? (dt.down ? downedLabel('down') : null)`，不再直接写 `downedLabel(downed)`。
- `:734-741`：note 也按实际 label 走；相同 label 时：
  - 濒死 → “本来就已经是濒死，倒计时没有重置”

  - 其他 → `状态已经是「...」，这次没有变`
- `:740`：变化时写 `HP 归零 → ${actualLabel}`。

**实测结果**

| 场景 | token 实际 status | status delta | note |
|---|---|---|---|
| 非战斗、旧 `急救机器人`、HP0、摔 12 | 仍是机器人（但 `endsAt` 被重置） | **无** | “状态已经是「急救机器人正在赶来」，这次没有变” → P2-1 的文案与实际 ETA 改动不符 |
| 非战斗、无状态、HP0、摔 12 | 机器人 | `from:null → to:'急救机器人正在赶来'` | “→ 急救机器人正在赶来” |
| 战斗、无状态、HP0、摔 12 | 濒死 + roundsLeft 3 | `to:'濒死'` | “→ 濒死”（既有的“必摔”测试也通过） |
| 非战斗、旧 `濒死`、HP0、摔 8/12 | 仍濒死、不重置 roundsLeft | 无 | “本来就已经是濒死” |
| 战斗、旧机器人、HP0、摔 12 | 濒死 | 机器人→濒死 | “→ 濒死” |

**结论**：声称的“不写假的 →濒死”已生效；旧机器人高摔不写 delta 也生效；但因为是重置对象而不仅是保留对象，产生了 P2-1 的静默 ETA 改动。
