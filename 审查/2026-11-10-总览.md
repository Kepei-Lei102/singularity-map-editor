## 最重要的一句话

**代码里已经实现的东西，比你以为的少；测试全绿，但有一大块绿是给空转骨架背书的。**

- `src/rules/` 240 个导出里：**8 个真死、25 个只有测试在用、44 个只在自己文件里用**。
- `interaction.ts` 724 行里约 **300 行只有测试在调**（动作卡的声明层/施加层：`planEffects`、`applyTransitions`、`checkPreconditions`、`resolveOutcomes`……）。
- `actions.json`（186 张动作卡）在 `src/` 里**零引用**，且字段结构喂不进 `ActionDef`（连必填的 `outcomes` 都没有）。

- `resolveJump`（jump.ts:273）0 调用，生产走的是 `trial.settleJump`（另写一份），而 49 条跳跃测试测的是前者——**玩家真正走的那条 0 测试**。

## 四条跨层的主题

### 主题一：判定口径只剩「公式」，但「判定」还有 5 条路径

| 路径 | 谁在用 | 状态 |
| --- | --- | --- |
| `resolveCheck`/`resolveChecks` | 跳跃、感知、跳跃结算 | ✅ 唯一公式 |
| `resolve()` | 只有 `skillCast`（且属性全 0） | 半死 |
| `attackBand`/`rollAttack` | 攻击、借机攻击 | 活的独立口径 |
| `rollRescue` | 救治 | 活的独立口径 |
| `resolveLuck` | 无人调用 | 死 |

且引擎外还散着「骰几面、对多少 DC」的知识（`jumpScale`），攻击阈值在 `attackBand` 与 `tierOfRoll` 里逐字重复两遍。
D100 的 000 补投链**只在测试里活着**：`resolve()` 偷用第一项属性的第二颗骰当补投，生产唯一调用方只传一颗；
`resolveCheck` 干脆传 `undefined`（`interaction.ts:145`），D100 切过去那天会静默丢极值规则。

### 主题二：优劣势骰在协议层表达不出来（唯一 P0）

`judge-roll` 消息只带 `value: number`（`sync.ts:27`），`judgmentResult` 同样一个值。
所以「往下 3–5 格 = 劣势敏捷」在玩家自己掷骰时被当成单颗——**难度被静默降低**。
这不是忘了写：`JumpRequest.dice` 已经传到面板，但消息格式装不下两颗骰。
修法见 ui 报告 P0-1（协议加 `values: number[]`，玩家端连掷两颗，面板显示「掷出 a/b，采信 b」）。

### 主题三：状态账本与消息可信度

- 回合账本：`runMode`/`runTurns` 跨回合不清（`trial.ts:666`）；`acted`/`runMode`/`sharpAttack` **全队一份**不是每人一份（`store.ts:253`）；尸体和昏厥能走能打（没有 gate）。
- 判定归属：`judgmentResult` 没和 `pendingJudgment` 绑定 → 取消一笔判定后，上一颗骰子会被当成新判定的结果，并写进永久判定记录。
- 跨窗口：`judge-roll` 主持人侧**零校验**，PostMessage 与 BroadcastChannel 两条路都能塞进 `D20 = 999`；
  玩家点「同意」会命中撞号分支 → `renewSession()` → 所有玩家窗口永久掉线。

### 主题四：性能与耦合的代价

- `visiblePoint` 每次调用重建整张全图代价表，却在滑动（每格）、攻击目标枚举（每目标）、物件可见性（每子格）的内层循环里调 → 大图明显卡。
- `render.ts:483` 选中棋子时**每次重绘都跑一遍全图视野**。
- `update()` 每次都跑 `withVision` + `syncMemory`，`syncMemory` 按人 `cloneLayer` 整层复制（fog + subFog）→ 在 Inspector 里敲一个字都付这个代价。
- `core/store.ts` 扇入 27，连 `rules/judgments`、`rules/dialogue`、`rules/skillCast` 都直接 import 全局状态；规则层无法脱离 app 单测。
- 真环只有 1 组：`actions → sync → dialogue → actions`（`skills-data ↔ skills` 只是 `import type`，脚本误报）。
