# 地形：大格与 1/3 子格

## 数据

- 大格地形：`GameMap.cells`，一格一个 terrain id。
- 子格覆盖：`GameMap.subCells`，key = `sy3 * (width*3) + sx3`，只在细分过的格子里生效。
- 没有覆盖时退回大格地形；**不允许别的地方再写一套 fallback**。

读取统一走 [`src/scene/terrain.ts`](../src/scene/terrain.ts)：

- `isSubdivided` / `subKey`
- `terrainAtSubcell` / `terrainAtPoint`
- `terrainBlockers` / `terrainBlocksRect` / `terrainBlocksPoint`
- `terrainVisionCoef`（只看大格系数；子格遮挡在 `src/scene/sight.ts` 里单独处理）

写入统一走 [`src/runtime/actions.ts`](../src/runtime/actions.ts)：

- `paintTerrainCells`：改大格，并清掉这一格下残留的子格覆盖
- `paintTerrainSubcells`：改子格；落在没细分的格子会顺手细分，并把新子格的迷雾/记忆初始化成和大格一致

## 已生效

- 编辑器渲染、玩家窗口渲染：细分格按子格取地形，没覆盖退回大格。
- 玩家迷雾/记忆：`seen.subCells` 记的是当时的实际子格地形。
- 视线：主格衰减仍按大格系数；细分格再用 1/3 精度判断射线有没有穿过完全挡死的小块（`visionCoef ≥ 99`，比如墙）。草丛、窗这类衰减系数仍按整格算，不做子格级衰减。
- 移动/推箱：按 1/3 小格判定不可通行地形；空白地形仍算不可通行。
- 画笔/橡皮/矩形填充：小格模式下按小格写，大格模式下按整格写并清覆盖。
- 改地图尺寸：`subCells` 跟着平移。

## 兼容

旧版「取消细分」只清了记忆，没清地图上的 `subCells`（`f6d9758` 才补上删除）。那种存档会留下
父格已经不在 `subdivisions` 里的子格键，导出前的严格校验会报
「子格地形只能落在细分过的格子里」。现在加载和导入都会先跑 `repairOrphanSubcells`：
把这些找不到父格的 `subCells` / `materialSubCells` / 子格迷雾键丢掉（取消细分本来就是要丢这一格的子格数据），
仍然有效的子格不动。刷新一次编辑器再导出即可。
