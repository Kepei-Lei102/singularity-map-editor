# 地形：大格与原生 3×3 小格

## 数据

- 大格地形：`GameMap.cells`，一格一个 terrain id；规则层（移动距离、射程、D100、迷雾）仍按这一层。
- 小格地形：`GameMap.fineCells: string[]`，长度固定 `width * height * 9`，key = `y3 * (width*3) + x3`。
- 每个大格固定自带 3×3 小格，没有「细分 / 取消细分」状态，也不需要先圈区域；任何大格都能有细格细节。
- `cells` 是大格底；`fineCells` 是完整的 9 格。新建/迁移时 9 格都填成大格底。
- 小格材质覆盖是稀疏表 `GameMap.fineMaterials?: Record<number, Id>`，见 [`材质层-v0.1.md`](材质层-v0.1.md)。

读取统一走 [`src/scene/terrain.ts`](../src/scene/terrain.ts)：

- `subKey` / `hasFineDetail` / `isSubdivided`（`isSubdivided` 现在等于「这一大格有细格细节」）
- `terrainAtSubcell` / `terrainAtPoint`
- `terrainBlockers` / `terrainBlocksRect` / `terrainBlocksPoint`

写入统一走 [`src/runtime/actions.ts`](../src/runtime/actions.ts)：

- `paintTerrainCells`：改大格，并把这一格的 9 个小格一起铺成同一地形。
- `paintTerrainSubcells`：只改指定小格；不再需要先细分。
- `fillEmptyCells`：只把真正空白（大格底为空且没有小格细节）的大格铺成某地形，同时铺它的 9 个小格；已有小格细节的格不算空白格。
- 删除地形：清掉 `cells` 和 `fineCells` 里的旧 id；小格退回它所在大格的底。

## 已生效

- 编辑器渲染、玩家窗口渲染：按小格取地形；正常时 9 格等于大格底，小格改过就按改过的值。
- 渲染 LOD：小格在屏幕上小于 4px 时，整个大格合并成一块颜色，取 3×3 里出现最多的地形；作者打开「小格编辑」或「显示子格线」时强制按真实小格画。
- 迷雾/记忆仍按大格：`fog`、`seen.cells`、`cellRevs` 都没有小格版本；小格只影响地形和遮挡。
- 视线：有细格细节的大格，整格衰减在“非完全挡死”的小格里取多数派系数（窗 0.5、洞 0、草丛照旧）；`visionCoef ≥ 99` 的小墙不参与整格系数，交给 1/3 精确遮挡。这样 base 是墙、9 格全 floor/window 能降回来，也不会让多数小墙压掉穿过 floor 的射线。草丛、窗这类系数仍按整格算，不做小格级累加。
- 移动/推箱/房间布局：有细格细节的大格里按 1/3 小格判定不可通行地形；空白/未登记地形仍算不可通行，房间排布也会拒绝。家具滑行和房间排布的目标位置也会查小格墙。
- 画笔/橡皮/矩形填充：小格模式下按 1/3 小格写；大格模式下按整格写并覆盖 9 个小格。
- 改地图尺寸：`fineCells` 和 `fineMaterials` 的 key 跟着平移；记忆里的 `observed` / `architectureRevs` 也按小格 key 平移。

## 还没做

- 独立材质层已做纯色版；贴图、脚步声、摩擦规则还没接。
- 小格只细化「完全挡死」的遮挡；草丛/窗这类衰减系数如果以后要按小格渐变，再单独开一版。
- 小格迷雾：现在有意不做第二份小格 `fog`，避免每张图再存一份完整小格数组。玩家看到的是大格可见范围里的小格地形。

## 兼容

- v1 存档（粗格 `cells` + 稀疏 `subCells` + `materialSubCells`）加载/导入时迁移成完整 `fineCells` / `fineMaterials`，并把版本改成 2。
- 旧版「取消细分」留下的孤儿键（父格已不在 `subdivisions` 里）不会再长回来：迁移时只接受父格仍在 `subdivisions` 列表里的键，坏 key/出界 key 直接丢掉。
- 旧字段 `subdivisions` / `subCells` / `subFog` / `materialSubCells` 迁移后从存档里删除。
