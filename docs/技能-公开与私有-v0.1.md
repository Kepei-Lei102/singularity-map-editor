# 技能：公开与私有

技能数据随编辑器走（`src/rules/skills.ts`），角色身上只记技能 id（`PC.skills`）。

## 公开（可以出现在玩家窗口、玩家说明里）

- `id`、`name`、`pathway`、`group`、`sequence`
- `desc`：玩家说明
- `me`：发动消耗（玩家需要知道要不要付得起）

唯一出口是 `publicSkillsOf()`（`src/rules/skills.ts`）。玩家窗口只拿这个投影，
玩家端不 import `SKILL_LIBRARY`，所以整张技能表不会随玩家端发出去。

## 私有（只在主持人侧）

- `check`：判定口径
- `actionId`：指向公共动作卡（映射关系涉密）
- 效果表 / 结算实现
- 解锁明细（途径、序列、技能 → 动作的对应）
- 动作库里的具体实现

## 约束

- 玩家端（`PlayerView`）只认 `PublicSkill` 类型，不读技能库。
- 主持人也只能看到自己可发动的部分（不然会爆蓝条）：锁定的技能默认不列，升级视图里才显示名字。
- 以后动作卡 `actions.json` 生成时，解锁映射必须从公开包里剥掉。

## 校验

`scripts/skills.test.mjs`：公开投影的字段集合固定；`check` / `actionId` 不会出现。
