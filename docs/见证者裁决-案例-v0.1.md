# 见证者裁决：判例 v0.1

拿去打架用。每条都写清"动作库原文怎么说、三种裁法各站什么理、我们选哪个、什么时候可以改判"。

---

## 判例 1 · 【偷窃】（仅见证者裁决）

**场景**：酒廊，人挤。玩家说"我顺手把他腰上的通行卡摸了"。

**动作库原文**：判定口径＝「仅见证者裁决」，属性栏写「见证者裁决」，依据栏为空。

**三种裁法**

| 裁法 | 站什么理 | 结果 |
|---|---|---|
| A 直接给 | 口径写明只由见证者定，不掷骰 | 见证者问一句"周围有人看吗"，没人看见就给 |
| B 拆成两掷 | 偷＝敏捷，被看见＝观察，分开判更公平 | 两掷，一失手就暴露 |
| C 全推给玩家演 | "你怎么偷的？"说得过去就成 | 具身表演替代检定 |

**我们的裁法：A，但先问一句环境。**
判据：**这条口径存在的意义就是"不掷骰"，拆成两掷等于把它改成另一个动作。**
环境问题（有没有人看、有没有监控）不是检定，是事实，见证者直接回答。

**什么情况改判**：目标本身是智慧个体且正在警觉状态（相当于对抗）——这时改用判例 3 的拼点逻辑，让对方掷一次观察。

## 判例 2 · 【嘴炮】（仅见证者裁决）

**场景**：暴风兵拦路。玩家说"我用嘴炮说服他放我们过去"。

**动作库原文**：口径＝「仅见证者裁决」，属性栏「见证者裁决」。

**三种裁法**

| 裁法 | 站什么理 | 结果 |
|---|---|---|
| A 看内容 | 话有没有击中这个 NPC 在乎的东西 | 说中了就过，说空话就不过 |
| B 看魅力 | 魅力高的人说话就该好使 | 掷魅力 |
| C 看玩家本人的表演 | 玩家真的说出那句话才算 | 说不出口就不算 |

**我们的裁法：A，C 作为加分项，B 不用。**
判据：**嘴炮的本质是"说对了什么"，不是"说得多好听"。** 一个魅力很低但说中要害的人，应该成功。
C 只有在玩家愿意当场把那句话说出来时才加——这是 META 游戏的鼓励方向，不是门槛。

**什么情况改判**：对方是纯功能性角色（没有心理弱点）——那就退回 B，或者直接判定"这种人说不通"。

## 判例 3 · 【决斗】（双方对照检定）

**场景**：玩家接受挑战，要跟对方决斗定输赢。

**动作库原文**：判定口径＝「双方对照检定」，属性「【魅力】→对方【意志】」，依据「作者确认 魅力拼点对方意志，成功则进行决斗」。

**裁法（唯一）：**
两边各掷 D20，加各自属性区值，高者赢。**平手算没做成。**
属性差 ≥4 时，高的一方掷优势、低的一方掷劣势（规则书那条阈值）。

**例子**：玩家魅力 65（区值 13）掷 12 → 25；对方意志 75（区值 15）掷 9 → 24。玩家赢。

**什么情况改判**：不存在的。这是动作库唯一一条拼点口径，不套 DC。
**注意**：跟智慧个体互动的其它动作（谈判之类）走的是另一条——规则书的 DC 修正：
最终 DC ＝ 20 −（A 区值 − B 区值）。两条不混。

## 判例 4 · 大失败该罚多重（现挂）

**场景**：玩家撬一把精密锁，掷出 1（大失败）。锁在实验室门上，旁边有警报。

**问题**：预置表里的"大失败"只写了"锁芯卡死"，但这一场的锁连着警报，罚轻了不像话，罚重了会把整场搞崩。

**三种裁法**

| 裁法 | 结果 |
|---|---|
| A 照表 | 锁芯卡死，仅此而已 |
| B 加罚 | 卡死＋触发警报，整层楼进入戒备 |
| C 现挂 | 见证者当场生成一条受限效果：`object-state → 门「卡死」`，外加一条 `token-status → 全队「被注意」` |

**我们的裁法：C，且必须走审核通道。**
判据：**大失败的罚则必须跟"这一场的代价结构"对齐，只能当场定。**
但现挂生成的是**受限效果**（改状态、挪位置、开关物件、挂状态），不是代码：
要能撤销（from/to）、要能回放（log 里一条）、要能同步到玩家窗口。这三条做不到的，就不许现挂。

**什么情况改判**：这场没有代价结构（比如教学场）——用 A，别加罚。
