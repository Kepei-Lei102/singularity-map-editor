# 动作库数据（actions.json / actions-unlock.json）

来源：`《奇点之后》动作库 V2.1.1(2).xlsx`（只读，放在 `/Volumes/No Access/`）。

## 两份文件的分工

| 文件 | 位置 | 内容 | 能不能公开 |
|---|---|---|---|
| `actions.json` | `src/rules/actions.json`（随仓库） | 动作卡：编号、名称、分类、检定属性、判定口径、判定依据、释义；分类说明；36 个白卡默认动作 | 公开 |
| `actions-unlock.json` | `私档/actions-unlock.json`（已被 .gitignore 挡住） | 解锁明细：动作 ↔ 途径 / 序列 / 技能序号 / 技能名 / 来源文件；按技能、按动作聚合 | 私有 |

公开版**没有**：解锁条目数、涉及途径数、首个来源、全部解锁来源、技能增强版、解锁明细。

## 释义的清洗

`动作释义` 表里有一部分释义是从技能「作用」栏提炼的，会顺带写出“来源：某途径某序列某技能”。公开版按分句删掉含以下内容的分句：

- 任意技能名（来自解锁明细）
- 任意途径名
- `序列` + 数字
- `来源：` / `来源技能` / `来源文件`

删完为空的动作有 10 条（愚弄、点拨、伪声、按摩、援护、望气、相景、网暴、羞辱、谎言），原始释义本身也只是“来源技能未填作用栏，待补”或只在讲与另一个技能的关系。完整释义留在私有侧的表里。

## 重新生成

工作簿改版后跑：

```bash
python3 scripts/gen-actions.py [动作库.xlsx] [私有输出路径]
```

脚本自带自检：公开文件里出现技能名、途径名、`序列`、来源线索就直接失败；字段集合固定为 `version / source / categories / actions / defaults`。

当前产物：186 个动作、12 个分类、36 个白卡默认动作；私有侧 344 条解锁、249 个技能、186 个动作。
