# 正式判定：没有私骰，落定即广播

## 规则

1. **见证者的骰子不能取消发布**。骰子落定后，结果必须广播，不能丢弃、不能换骰重掷。
2. **掷之前先确认设置**。判定名称、发生角色、骰子面数、裁定都要在掷之前锁定；锁定后界面不再允许改选项。
3. **没有私骰**。`publishJudgment` 忽略调用方传的接收者，一律发给当前全队的每个角色；界面里不再有「某角色（私密）」选项。
4. **视野外只给通知**。判定以「发生角色」身上棋子的位置作为发生点：
   - 发生角色自己永远看到完整判定；
   - 同图且能看见这个位置的其他角色看到完整判定；
   - 看不见、或没有棋子在场的角色，玩家端只显示「发生了一次判定」，不发送标题、骰点、裁定。
   - 没有指定发生角色、或该角色没有棋子时，不做遮蔽，全队看到细节。

## 实现

- [src/rules/judgments.ts](../src/rules/judgments.ts)：`publishJudgment` 强制广播全队，校验 `subjectId` / `place`。
- [src/components/JudgmentPanel.tsx](../src/components/JudgmentPanel.tsx)：确认设置 → 掷骰 → 自动广播；没有丢弃按钮；落定后选项锁定。
- [src/runtime/sync.ts](../src/runtime/sync.ts)：`playerWorld` 按 `subjectId` / `place` 算可见性；不可见时把 `judgments` 清空，只给 `judgmentNotice`。
- [src/components/PlayerView.tsx](../src/components/PlayerView.tsx)：显示「发生了一次判定」。
- `DiceJudgment.place`：`{ mapId, x, y }`，坐标用棋子实际坐标（可以带小数）。

## 兼容

旧存档里已经有 `recipients` 子集的判定，仍然按旧接收者过滤；新判定一律全队。
