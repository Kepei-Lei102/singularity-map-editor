# 独立材质层 v0.1

地形决定通行和视线；材质只决定表面。两层分开，改地板颜色不会改墙的通行，改墙也不会丢地板。

## 数据

- 材质表：`World.materials`（`id / name / color`），默认带木、石、瓷砖、金属、地毯。
- 大格材质：`GameMap.materialCells`，key = 主格序号。
- 小格材质覆盖：`GameMap.fineMaterials?: Record<number, Id>`，key = `y3 * (width*3) + x3`；没有覆盖的小格退回这一格的大格材质。
- 没有「细分 / 取消细分」状态：任何大格都能写小格材质覆盖。
- 记忆：`Memory.materialCells`，只记大格材质；小格材质不进记忆（记忆仍按大格）。
- 预留字段：`texture`（贴图媒体 ID）、`footstep`（脚步声媒体 ID）、`friction`（0–10）。现在只存不用。

读取统一走 [`src/scene/material.ts`](../src/scene/material.ts)：

- `materialAtCell` / `materialAtSubcell` / `materialAtPoint`
- `rememberedMaterialAtCell` / `rememberedMaterialAtSubcell`（后者也只读大格记忆）

写入统一走 [`src/runtime/actions.ts`](../src/runtime/actions.ts)：

- `paintMaterialCells`：改大格材质，并清掉这一格下的 9 个小格材质覆盖，回到大格底。
- `paintMaterialSubcells`：写小格材质覆盖；不再需要先细分。
- 删除材质：小格覆盖里指向它的 key 直接删掉，读取时自然退回大格材质。

## 已生效

- 编辑器左侧「材质层」：选材质后画笔/矩形/橡皮切到材质层；「地形层 / 材质层」按钮可以随时切回去。橡皮只擦材质，不碰地形。
- 渲染：大格材质铺底，小格材质覆盖在上面（半透明叠加），大格和 1/3 小格都支持。
- 渲染 LOD：小格小于 4px 时材质也取 3×3 里出现最多的那个；打开小格编辑/子格线时按真实小格画。
- 玩家窗口：只发当前看得见的大格材质和小格覆盖；离开视野后显示 `seen` 里的记忆材质。没见过的材质不发，材质表也只发用到的。
- 迷雾：材质跟随大格一起被看见/记住；小格覆盖只在当前可见的大格里发；不参与视线、不挡路、不改变通行。
- 扩图/改尺寸：`fineMaterials` 的 key 跟着平移。
- 存档校验：材质表、地图两层、记忆层都有 schema 检查；v1 的 `materialSubCells` 迁移成 `fineMaterials`。

## 还没做

- 贴图渲染：`texture` 只是字段，画布现在只画纯色；第二刀会接物件自带 / 地形贴图组 / 独立贴花。
- 脚步声：`footstep` 只是字段，移动/试玩还没播声音。
- 摩擦规则：`friction` 只是字段，还没接到移动、滑行或物理互动。
- 材质参与互动：触感、材质覆盖效果表（`ObjectProfile.material` 是物件档案，不是这一层地板材质，两者以后可以互相引用，但现在还没绑）。
- 材质层单独导入/导出面板；现在跟工程文件一起走。
