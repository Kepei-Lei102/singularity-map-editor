# 独立材质层 v0.1

地形决定通行和视线；材质只决定表面。两层分开，改地板颜色不会改墙的通行，改墙也不会丢地板。

## 数据

- 材质表：`World.materials`（`id / name / color`），默认带木、石、瓷砖、金属、地毯。
- 大格材质：`GameMap.materialCells`，key = 主格序号。
- 子格材质：`GameMap.materialSubCells`，key = `sy3 * (width*3) + sx3`；只在细分过的格子里生效，没覆盖的退回这一格的大格材质。
- 记忆：`Memory.materialCells` / `Memory.materialSubCells`，记的是上一次看见时的材质，不随实时层改。
- 预留字段：`texture`（贴图媒体 ID）、`footstep`（脚步声媒体 ID）、`friction`（0–10）。现在只存不用。

读取统一走 [`src/scene/material.ts`](../src/scene/material.ts)：

- `materialAtCell` / `materialAtSubcell` / `materialAtPoint`
- `rememberedMaterialAtCell` / `rememberedMaterialAtSubcell`

写入统一走 [`src/runtime/actions.ts`](../src/runtime/actions.ts)：

- `paintMaterialCells`：改大格材质，并清掉这一格下的子格材质覆盖
- `paintMaterialSubcells`：改子格材质；落在没细分的格子会顺手细分

## 已生效

- 编辑器左侧「材质层」：选材质后画笔/矩形/橡皮切到材质层；「地形层 / 材质层」按钮可以随时切回去。橡皮只擦材质，不碰地形。
- 渲染：材质覆盖在地形颜色上（半透明叠加），大格和 1/3 小格都支持。
- 玩家窗口：只发当前看得见的材质；离开视野后显示 `seen` 里的记忆材质。没见过的材质不发，材质表也只发用到的。
- 迷雾：材质跟随地形一起被看见/记住；不参与视线、不挡路、不改变通行。
- 扩图/取消细分：材质 key 跟着平移；取消细分会清掉子格材质覆盖。
- 存档校验：材质表、地图两层、记忆两层都有 schema 检查。

## 还没做

- 脚步声：`footstep` 只是字段，移动/试玩还没播声音。
- 摩擦规则：`friction` 只是字段，还没接到移动、滑行或物理互动。
- 材质参与互动：触感、材质覆盖效果表（`ObjectProfile.material` 是物件档案，不是这一层地板材质，两者以后可以互相引用，但现在还没绑）。
- 材质层导入/导出单独的面板；现在跟工程文件一起走。
