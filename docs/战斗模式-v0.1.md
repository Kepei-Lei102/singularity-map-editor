# 战斗模式 v0.1（最小闭环）

先把一场小战斗跑通：行动点、攻击、扣血、濒死。v0.2 接上了整轮边界和流血/中毒/眩晕的自动结算；技能/动作产生状态还没接。

## 已经生效

- **行动点**：战斗模式里每回合 1 点。攻击用掉就算用完，HUD 显示「行动点 1/1」。结束回合（空格）恢复。
- **移动**：每回合 5 格（15 个子步），移动不占行动点。
- **攻击距离**：周围 8 格，按格距（横走纵走加起来）算。
- **攻击判定**：D100，只看骰面，不看 DC（攻击是唯一不看属性的判定）。
  | 骰面 | 档 | 伤害骰 |
  | --- | --- | --- |
  | 000（记作 100） | 特大成功 | 默认 1D8 → **4D8** |
  | 95–99 | 大成功 | 1D8 → **2D8** |
  | 6–94 | 命中 | 1D8 |
  | 1–5 | 落空 | 不掷 |
- **伤害**：默认 1D8。档位决定掷几颗，**不是把一颗骰乘几倍**。
- **暴击按轮结算**（2026-11-21 定）：大成功拆 **2 轮**、特大成功拆 **4 轮**，每轮 1D8，逐轮扣 HP；目标在某一轮倒下后，后面的轮次不再结算。009 打已眩晕目标的 ×5 按每轮颗数乘（大成功每轮 5 颗、共 10 颗）。007 的暴击额外 1D8 落在第一轮。
- **扣血**：扣目标角色卡上的当前 HP，不会扣成负数。
- **濒死**：HP 归零标「濒死」状态（3 回合）；3 整轮无人救治就撕卡，不直接死。
- **看不见就不能打**：目标必须在视野里（按棋子的朝向和遮挡算）。
- 攻击结果写在试玩 HUD 的状态行里（「进攻方 攻击 目标：D100=28，伤害 3；目标 HP 6→3/6」）。
- 属性判定（跳跃、感知、互动）不看攻击这套：一律**骰点 ＋ 属性值 严格大于 DC**，
  D20 区掷 D20 对 DC 20（属性值 = 属性 ÷ 5），D100 区掷 D100 对 DC 100。见 `物理互动-范式-v0.1.md`。

## 角色卡

队伍面板里每个角色多了「六维与 HP」：

- 六维填总属性，旁边显示区值（÷5 向下取整）。
- HP 上限默认按规则书算：0.4×魅力 + 0.3×力量 + 0.2×敏捷 + 0.1×意志，用区值代入；填了就用你填的。
- 当前 HP 单独存，被攻击时扣的就是它。

## 借机攻击（2026-11-07 定稿）

口径改成**贴身脱离**，不再按规则书原文「进入敌方周围 8 格」算：

- 原本已经贴在敌人身边（**1–2 格**），往外挪的那一步触发；
- 在远端进出不管；
- **每步弹提示**，主持人点「打」才结算——不自动打，因为打出去有可能反而更亏；
- **一个敌人在自己回合外只能借机一次**，结束回合后全部重新亮起；
- 判定：**走攻击口径**（作者 2026-11-10 定）。000 特大成功 / 1–5 落空 / 95–99 大成功 / 其余命中，
  即默认约 95% 命中率。不是「纯幸运骰 51+」——那条是 `resolveLuck()` 的口径，借机攻击不用它。
  技能将来可以改判据，但命中档位仍走攻击这套。
- **借机攻击也吃 009-9-003 被动**（2026-11-20 补）：借机者解锁眩晕打击时，命中且伤害骰出 8 或目标已知物理弱点 → 目标一回合眩晕；目标已经眩晕 → 这次伤害骰颗数 ×5。009 是被动，不扣 ME。
- 借机攻击默认钝器：非濒死、非已昏厥目标的 HP 归零按**昏厥**处理，不标濒死，也不再往上叠眩晕。
- 借机攻击按每个出手的敌人落一条事件账本（命中/落空都记）。**PC 目标 0 HP / 濒死 / 昏厥时不结算**，和普通攻击同口径；NPC 目标 0 HP 仍可被攻击（伤害不再变化）。已濒死 NPC 只扣 HP、保持濒死；已昏厥 NPC 只清掉旧状态，不再改成别的状态。

规则书原文那条要改（已经记在这里，回头一起改知识库）。

## 移动限制

- 贴身缠斗中（敌人在 1–2 格内），一次只能挪 1 格；
- 棋子只有上下左右四个方向，斜走本来就不存在；
- 战斗模式里玩家之间可以**互相路过**，但**不能停在同一个格子上**（落点会拦）。

## 救治

- 用的是动作库 **#119【救治】**（医疗·调养，敏捷单属性），不是随便谁都能救；
- 要解锁急救/救治类技能才做得了：`011-9-102`肾上腺素、`011-9-002`通用药包、`011-9-201`治疗禁药、`011-9-204`强制治疗、`009-9-104`士气激励；
- 敏捷 D100：投 1 没救回来，其余算成功；成功把人拉到**至少 1 HP**（原本更高就保留），濒死/昏厥解除；
- 要贴身（2 格内），占 1 行动点。

## 昏厥与濒死（钝器 / 锐器）

HP 归零之后去哪儿，看这一击用的是钝器还是锐器：

- **钝器**（默认）：晕过去，标签「昏厥」，躺在原地，不撕卡；非你死我活的场景战斗结束后自动醒。
- **锐器**：标签「濒死」，3 回合内没人救治就撕卡。

怎么决定用哪种：

- 攻击时**临时勾选**「锐器」，不是固定写在角色身上；
- 只有角色卡勾了**「携带锐器」**的人，那个勾选框才亮；不带锐器的角色默认灰掉，勾不了；
- 没勾就是钝器。

## NPC 血条

- **所有 NPC 强制有 HP 上限**（作者 2026-11-21 定）：`hpMax` 没填或 ≤0 就按 10；80 血的大机器人填 `hpMax: 80`。
- `hp` 没填就按满血；HP 硬夹在 `[0, hpMax]`。提高生命值上限的技能改 `hpMax`，上限跟着新值走；目前还没有具体技能效果接入，先保留可变字段。**提高上限不回血**：明确填了 `hp` 就保留原值，要按新上限满血得手动把 `hp` 也改上去。
- 读档/导入/每次 update 时会把 NPC 的 `hpMax`/`hp` 归一写回：只填 `hp` 的旧 NPC 按默认上限 10 夹；80 血这种要补 `hpMax: 80`。已倒地/濒死但没填 `hp` 的旧数据按 0 处理。迁移把旧档 `hp` 超过写回上限（没填有效 `hpMax` 按 10，或超过 `hpMax`）夹小后会记一条日志提示；PC 棋子上的 raw `hp/hpMax` 会被清掉（PC 的血只认角色卡）。
- NPC 0 HP 仍可被攻击（只是伤害不再变化），不会从攻击目标里消失；PC 0 HP / 濒死 / 昏厥仍不能打，尸体仍然不能打。
- NPC 打空也走同一套：钝器「昏厥」、锐器「濒死」；中毒 tick、借机攻击、救治共用这个 HP 池。

## v0.2 已落地：回合边界与战斗状态

口径（作者 2026-11-19 定）：

- **一整轮 = 所有玩家各结束一次回合**。主持人手动切人；只有最后一个人结束才结算状态、`turn` 才加一。这样 4 人队里濒死的人能撑约 3 整轮，不会不到一轮就撕卡。尸体/昏厥的人算“这轮不再行动”，不要求主持人切过去按空格；同轮被救回来的人还能拿到自己的行动。已经结束的人再按空格不会重复结算，也不能再攻击/移动。
- **濒死**：每整轮减 1；减到 0 时角色卡标已死亡，棋子变尸体留在原地，写一条日志。NPC 不走撕卡。
- **流血**：每整轮掷 1D6 扣 HP；扣到 0 按锐器伤口进入濒死（不是昏厥）。流血本身**不挡行动**。
- **中毒**：每整轮掷 1D6，默认扣 HP；状态上可以标 `damageTarget: 'me'` 改扣 ME。中毒本身**不挡行动**。
- **眩晕**：轮到这个人时自动算他这回合已经用过行动点，HUD 提示「跳过这个回合」；结束自己的回合后解除。眩晕**挡行动**。
- 状态都挂在 `TokenStatus`：`damageDie` / `perRound` / `damageTarget` / `skipTurns` / `blocksAction`。固定伤害走 `perRound`，掷骰走 `damageDie`。
- **倒地口径**：尸体/昏厥不能换姿态、救人、感知、跑法、开门/撬锁/撞门；仍可以被救、被拖。挂起的跳跃/门判定在真正挪人、开门、扣反伤之前复核，发起者已结束回合或被眩晕/昏厥时整笔取消，不挪棋子、不开门、不落事件；攻击挂起只认 D100，且按开判定时的发起者结算（主持人切到别人也不会拿那个人的手和 ME），发起者已结束回合/眩晕/昏厥/行动点已用掉就整笔收掉；骰面、tens/units 或 value 与判定对不上的记录只报错、不落地。撬锁挂起期间锁先被解开但门没开，仍按原判定开门（锁已开，不再重复写锁的 delta）；门已经开了才整笔收掉。结算前还会挡住重复的 rollId（攻击/撬锁），判定角色已经不在队伍里时直接收掉挂起。结束当前人的回合时，属于他的挂起判定一并收掉。

HUD 在战斗模式提供「流血 1 回合 / 中毒 1 回合 / 眩晕 1 回合」三个入口；技能/动作产生的状态从攻击技能包开始接。

## 攻击技能产生的状态

- `007-9-004 全力攻击`：攻击时在 HUD 选它，命中后随机一种：**暴击** / **流血** / **去除武器**；目标棋子上勾了「物理弱点已知」就随机两种且不重复。
  - 暴击按“这一击再补 1 颗 1D8”算，不是攻击档位的大成功（大成功仍按 ×2 伤害骰）。
  - 流血挂 `{damageDie:6, damageTarget:'hp', roundsLeft:1}`，每整轮 1D6 HP，不挡行动。
  - 去除武器挂 `{roundsLeft:1, blocksAction:false}`：这一回合不能用锐器，钝器照打。
- `007-9-203 灵巧攻击`：命中后随机一种：**眩晕** / **降智** / **恐惧**；攻击者知道目标的心理弱点就随机两种且不重复（按攻击者自己的认知算，不是全场共享）。
  - 眩晕跳过下一个自己的回合；恐惧 1 回合挡行动；降智立即造成 1D6 ME 伤害，目标没填 ME（NPC）就不落地，只写日志。
- `009-9-003 眩晕打击`：**被动**，不用选；近战伤害骰出 8，或目标已知物理弱点且命中，就给目标 1 回合眩晕。目标**已经眩晕**时，这一击的伤害骰颗数 ×5（普通命中 1 颗→5 颗，大成功 2 颗→10 颗）。
- 两个主动攻击技能各扣 1 ME：结算时扣，落空也扣；玩家取消判定则不扣。被动不扣。
- 弱点不是新数据源，就是棋子上面的两个勾。物理弱点仍按「主持人知道后勾『物理弱点已知』」的旧口径；心理弱点勾的是「客观上有没有」，再按每个角色勾「谁知道」——只有勾了的观察者才按已知弱点算，玩家载荷也只下发自己知道的那一份。队伍共享信息要主持人通过扮演过程逐个勾，勾本身不掷骰、不占行动点。
- 状态槽仍然只有一个：新状态**覆盖旧状态**，事件里会写清 from/to，不会静默丢。目标已经倒地（尸体/昏厥/濒死）时，不再往上叠攻击技能状态；昏厥目标的「降智」是即时 ME 伤害，照扣，尸体/濒死不结算任何附加效果。
- **ME 归零 = 被驱逐**（2026-11-20 定）：中毒把 ME 扣到 0 时，状态换成 `被驱逐`，不能行动；ME 恢复到至少 1 点后自动解除。不撕卡、不退出地图，GM 叙述被驱逐。

## 心理真伤（2026-11-25 第一包）

- 心理真伤**不单独成为一个动作**，只挂在已有动作上：本轮开放 `38 嘴炮`、`149 群嘲`（都是「仅见证者裁决」），由主持人把玩家说的那句话接成动作后按命中/落空结算。
- 已知目标心理弱点：1D8 ME；不知道：1D4 ME。没写「限一次」的动作可以反复打（可反复鞭尸）；技能文本自己写「限一次」的，由技能层另拦。
- 目标没有心理弱点也照走普通 ME 伤害 1D4，不冒充真伤；目标没填 ME 或 ME 已为 0 时不扣，事件账本写清「未落地 / 未再扣」，不写假公式。
- ME 归零 → `被驱逐`；ME 恢复到至少 1 点后，PC 和 NPC 都自动解除。
- 批评（8）/ 恐吓（18）的「多来源不同」效果接口、NPC 观察者的勾选 UI、技能级「限一次」还没有接，留到下一包。
