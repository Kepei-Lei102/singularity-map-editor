# 贴图组 v0.1

状态：编辑器可画、可保存在工程里，主持人本地窗口和玩家窗口都已能画出来。线上房间还没有把图片文件分块传给玩家，这一步等 `asset` 同步。

## 是什么

`CellGroup` 是「任意一组 1/3 小格 + 一张图」。它只改外观，不是地形、不是材质、不是物件：

- 不影响移动、通行、视线、迷雾、高度、D100 和任何判定；
- 不占用大格位置，也没有矩形/十字之类的限制；
- 一个组可以铺任意形状，格子是 `GameMap.fineCells` 的 key；
- 组有 `z`：地面 0–9，贴花 10–19；同一处后画的组按 `z` 覆盖；
- `objectId` 留给物件自带贴图（替换物件外观），v0.1 还没接物件外观，地面绘制会跳过这些组。

## 编辑

左侧「工具 → 贴图」，选「分组贴图」；右侧「贴图组」：

1. 点「＋ 新建」建一个空组，默认 `z = 0`；
2. 在地图上拖动，往组里涂 1/3 小格；Shift 拖动擦掉；
3. 可以改名、改层、选已有图片或上传一张图；
4. 「铺法」：`fill` 把整张图铺满整组的包围盒；`contain` 保持比例完整放进去；
5. 一次拖动只算一步撤销；新建、删除、改贴图也各自是一步。

同一个组换了图不会改动画在地图上的格子；删图只解掉贴图，格子还在。媒体库删除一张图时，会顺手把它在贴图组里的引用清掉。

## 渲染

画布顺序：地形底色 → 材质色 → 贴图组（按 `z`）→ 高度暖色 → 网格 → 物件。贴图用 `Path2D` 只裁出组里的小格，所以组可以任意形状，图按整组包围盒铺，不会被单格切开。

玩家窗口里，实时组只画 `fog === 1` 的格子；灰区（`fog === 2`）再画一遍 `seen.groups` 里记得的组，地形也按记忆判断，所以贴图不会在“看见 → 转灰”时突然消失。

图片按媒体 ID 懒加载：`world.media` 只有元数据，真正的文件在浏览器 IndexedDB；同一媒体 ID 换了内容会换存储名，缓存不会拿旧图。图片加载完会通知画布重画。

## 玩家载荷

- 实时层（`fog === 1`）只发看得见的组格子；一个组只要有一格可见就发；
- 整组都看见时才带整组 `bounds`。只看见一角时不带整组 `bounds`，渲染按可见格子的包围盒铺图，会在可见区域里局部拉伸；这样不会把看不见部分的形状/范围带给玩家；
- 灰区（`fog === 2`）从 `seen.groups` 发记得的格子和它被看见时的那一版贴图，带记得格子的 `bounds`；记得的格子玩家本来见过，不会再泄露新范围；
- 同一组在灰区会按贴图版本分开记：换图只影响当前看得见的格子，灰区格子留在它上次被看见时的旧图里；等这些格子再次看见，才换成当前版本；
- 组名和媒体文件名对玩家统一改成「贴图」，只留 `id`、贴图媒体 `id` 和存储名；
- 只带实时组和记忆组用到的 `world.media` 元数据，没用的图片不出现；
- 物件组（`objectId`）暂时不发，等物件外观那一步；
- 本地玩家窗口和主持人同源，能直接读同一份 IndexedDB，所以本地能显示；线上房间还缺文件同步。

## 存档与校验

- 旧 v2 工程导入时补 `groups: []`、`seen.groups: []` 和 `seen.groupRevs: {}`，不升 `world.version`；
- 记忆组内部用 `sourceId` 指回原组、`textureKey` 标贴图版本；玩家包里这两个字段会剥掉，记忆组 `id` 换成不透明的 `mg序号`，名字仍然只暴露「贴图」；
- schema 校验：组 ID 唯一、`cells` 是指定地图范围内的小格 key 且不重复、`texture.mediaId` 是合法 ID 且在 `world.media` 里、`fit` 只能是 `fill` / `contain`、`opacity` 在 0–1、`objectId` 必须指向本图物件；
- 扩图/改尺寸时组格子跟着平移，越界格子丢掉；物件被裁掉时它的物件组一起删掉；
- 复制地图时组跟着复制，物件组的 `objectId` 重映射到副本物件，玩家记忆不带过去。
